## Learned / surprises
- commitlint rejects subjects that start with a capital ("Money.add …", "GET …"); subjects
  are phrased as lowercase verbs instead. The rule stays on.
- Nest's router-level 404 sees `req.path` relative to the `/api/v1` router — `baseUrl + path`
  gives the full path for `instance`.
- PGlite boots in ~2–3 s alone, ~13 s when six spec files start in parallel → hookTimeout 30 s.
  `btree_gist`, `citext`, `pg_trgm` all ship in `@electric-sql/pglite/contrib/*`.
- Swagger UI under our CSP works (scripts are external files); two inline `<style>` blocks
  are dropped, which is cosmetic.
- `shadcn init` needs `-p nova` (preset names have no base prefix) and, with that preset, adds
  Geist, a grey palette, dark mode, a Button, `cn` from the official `cn` package and the
  whole `shadcn` package as a runtime dependency. Kept: config, alias, `cn`, CSS variants
  (as devDependency). Removed: the rest (ui.md decides the look).
- Inline `node -e` with backticks inside a double-quoted bash string gets command-substituted:
  write files with the editor tool instead.
